# Mi's Photobooth

## Description:

Mi's Photobooth is a Web Application that allows Users to create their own digital Photostripe. They can get the whole Photobooth experience at home.

Users can register, signin and (later) take Photos with their Webcam to generate personalized digital Photostrips, which they can download.

## Features:

Implemented
- User registration (Signup)
- User login (Signin)
- Email and password validation (6-15 characters)
- checking if User is already linked to an email 
- Password hashing with bcrypt
- MongoDB integration

Planned
- Webcam access
- Take 4 photos
- Generate a photostrip

- View saved photostrips : gallery
